# Instructions for LLM

## General Objective

This implementation aims to create an application of a shop list for grocery stores. The application can be used in a daily basis, and will store information about groceries the user will purchase, the price paid, and an history of prices to the user follow the price tendencies, inflation of product prices, and the best places to do groceries.

## LLM proactivity

The application will be implemented step-by-step, slowly and "bottom-up" (from scratch until a viable product). Do not add many extra content, placeholders and initial data, unless the user requests to do so.

The code should be clear and maintenable, being build incrementally.

## Versioning

It is up to the human developer to handle git in order to commit changes, reset undesired changes, and create branches.

## Code Styling

* Use clean code and KISS architecture.
* Refactor for shortness and readability.
* Use comments in scripts only when code is not obvious, or when really needed for TODO or placeholders.
* Script classes, functions and methods must have a documentation above them (a summary).

## Layout and Design

* Application title: "Shop Vibes".
* Language: Brazilian Portuguese.
* For design, it must be responsive to fit a mobile phone, and can be limited to look like a mobile app in desktop.
* Use a flat design (e.g Material design).
* Main theme color: #2577bf and white text.
* Secondary color: #BF2577 and white text.
* Tertiary color, if needed, for small items and footnote links: #77BF25 and white text.
* Default color: white background and black text.
